Projets réalisés

YouTube Playlist Extractor

Outil CLI modulaire en Python conçu avec une séparation stricte des responsabilités (CLI, service métier avec yt-dlp, persistance). Permet d'extraire rapidement les métadonnées de vidéos/playlists au format JSON et CSV, avec automatisation de la conversion audio en MP3 (192 kbps) via FFmpeg.

Python   yt-dlp   CLI   JSON/CSV   FFmpeg

App de Gestion de Groupes TD/TP

Application collaborative permettant d'optimiser et d'automatiser la répartition des étudiants en groupes de TD et TP universitaires. Conception et mise en œuvre d'algorithmes gloutons et de recherche par force brute combinés à une persistance de données robuste.

Java   PHP   SQL   Algorithmes Gloutons

Gestion Interactive de Résidences

Application de bureau collaborative dotée d'une logique métier complexe pour la gestion des résidences et des étudiants. Structuration selon le patron d'architecture MVC (Modèle-Vue-Contrôleur) pour un code maintenable et découplé, avec gestion collaborative sous GitLab.

Java   MVC   POO   Git / GitLab

2D Grid Game — C++ & SDL2

Jeu 2D sur grille en C++ utilisant SDL2 et SDL_image. Implémentation d'un moteur de tuiles (*tile-based*), d'animations par spritesheets (8 FPS), d'une détection fine des collisions et d'un dictionnaire de tuiles avec recherche dichotomique en O(log n). Gestion sécurisée de la mémoire via std::shared_ptr.

C++   SDL2   Recherche Dichotomique   POO
